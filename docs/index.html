Quick start

Senzing Bootcamp for Kiro

From nothing installed to a running bootcamp in Kiro’s agentic chat.

Get started

New to the bootcamp? Start at hub.senzing.com/bootcamp

Checklist

Before you start

  • Plan: 2000 Kiro credits.
  • Network access to the Senzing MCP server (https://mcp.senzing.com/mcp). The bootcamp cannot proceed without it. On a corporate network or VPN, ask for the domain mcp.senzing.com to be allowed.
  • A new, empty folder for the bootcamp.
  • Recommended, not mandatory: a business problem that needs entity resolution, and 5,000 to 20,000 records that illustrate it.

Six steps

Install and start

  1. Install Kiro.
  2. In a terminal, create a new, empty folder: 
    mkdir senzing-bootcamp
  3. Change into it: 
    cd senzing-bootcamp
  4. Start Kiro there: 
    kiro .

    Or: open Kiro and open a new project on an empty folder. This also works when the kiro command is not on your PATH.

  5. Install the Senzing Bootcamp Power:
    1. In Kiro’s left-hand icon bar, click the Powers icon.
    2. In the Powers panel, under Installed, click Add Custom Power.
    3. Select Import power from GitHub.
    4. Paste this GitHub repository URL: 
      https://github.com/Senzing/senzing-bootcamp-kiro-power/tree/main/senzing-bootcamp

    Paste the full URL, including /tree/main/senzing-bootcamp. The power is in that subfolder; the repository root URL is not a power.

  6. In Kiro’s agentic chat, enter: 
    Start the bootcamp

Kiro’s agentic chat will guide you through the bootcamp.

After you start

What happens next

The bootcamp first asks you to choose your curriculum, level of detail, and programming language, then guides you module by module. See every module

Good to know

Tips

  • Model and effort: set them in Kiro’s chat model selector. The bootcamp suggests a model and effort at the start of each module, and only you, the Bootcamper, can change the setting.
